A fast, dependency-free drop-in replacement for marked 18.1.3 (default options: GFM on, breaks off). `parse(markdown)` returns exactly the HTML marked renders, for CommonMark 0.31.2 + GFM 0.29 inputs.

## Run it

```sh
MAKEFUN_INPUT_DIR=<dir with cases.json> MAKEFUN_OUTPUT_DIR=<out dir> node main.ts
```
